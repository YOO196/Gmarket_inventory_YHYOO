# 재고 내부·외부 연계 적용지침

최종 수정일: 2026-10-13

## 1. 적용 상태와 범위

- 사용자 요청에 따라 문서에 적용한 **프로젝트 운영기준**이다. 쿠팡·B마트의 실제 SOP(표준 업무 절차) 또는 다른 팀의 합의 완료로 표시하지 않는다.
- 수동 보충 요청·수동 보충작업 생성은 제외한다. 시스템이 보충량을 계산하고 MOV(센터 내부 이동·적치·보충) 작업을 자동 생성하며, 작업자는 실제 이동·스캔·수량 확인을 수행한다.
- 자동 보충은 피킹선반 보충에 적용한다. 구매 발주, 센터 간 이송 할당, 담당자 재배정의 수동 업무와 구분한다.
- 내부 기준과 외부 연계 방식을 함께 적용한다. 외부 시스템 미연결·필수 설정 미등록은 '설정/연계 대기'로 표시하고 해당 처리를 보류한다.
- 자동 계산·상태 반영의 통합 참조는 [자동시스템 통합관리](../04_시스템_화면/01_자동시스템_통합관리.md)다.
- 기존 PO(구매발주) 유지·ASN(공급사 납품예정) 수정/새 차수의 이월 정의는 유지한다. 새 이월대장·다음 PO 연결 방식은 추가하지 않는다.

## 2. 내부 적용기준

| ID | 항목 | 적용 지침 | 완료·차단 기준 |
|---|---|---|---|
| I-01 | 관리 단위 | 상품 × 센터 × 위치 × 로트 × 상태. 수량은 기준단위 저장, 박스·묶음은 등록 환산값 사용 | 환산값 미등록·변경 충돌이면 확정 차단 |
| I-02 | 수량 구분 | 현물·판매적합·예약/할당·격리·예정·센터 간 이동중을 분리. 동일 물량 중복 집계 금지 | 예정은 현물 제외, 격리는 현물 포함·판매 제외 |
| I-03 | 로트 | 입고일·공급사·상품·소비기한으로 구분. 확인된 제조/공급사 로트가 다르면 추가 분리. 내부 ID·외부 로트값 보존. 확정 로트 자동 병합 금지 | 필수 추적정보 미확인은 보류 상태로 인수·분리 보관, 판매 제외 후 확인 |
| I-04 | 혼재·위치 | 상품·로트·상태를 실물 표시와 구획으로 구별할 수 있을 때만 혼재. 보관조건·사용 상태·수용량 확인 | 식별 불가·보관조건 불일치·초과 용량은 적치 차단 |
| I-05 | 적치·이동 | 출발·상품·로트·목적지 스캔, 실제 수량 확정. 분할 이동은 목적지별 완료/잔량 기록. 이동중 중단 시 임시 위치 기록 | 정상 내부 이동은 출발 감소·목적지 증가를 함께 반영, 센터 총량 유지 |
| I-06 | 자동 보충 | 최소수량 이하 시 목표수량까지 계산. 진행 중 보충과 출발 재고의 기존 배정량을 제외하여 MOV 자동 생성 | 기준 미등록·출발 재고 부족·목적지 부족은 예외 대기. 수동 보충 요청/생성 없음 |
| I-07 | 실사 | 품목·위치별 순환 실사 기본. 계수 대상 위치의 수량 변동 작업만 잠금. 진행 작업 정리 후 계수 | 잠금 실패 시 계수 시작 보류. 전수 실사는 별도 계획 |
| I-08 | 재계수·조정 | 첫 계수는 장부수량 숨김. 차이 시 다른 작업자 재계수·기준시각 이후 변동 대조. 원인 미확정은 조사 대기 | ADJ(재고 조정) 요청자와 승인자 분리. 승인된 조정만 한 번 반영 |
| I-09 | 격리 | 이상 수량·로트·발견 위치·사유·시각 기록, 실물 분리. 격리 상태의 일반 피킹/보충 차단 | 품질담당 근거·해제 승인 없이 판매 재개 금지 |
| I-10 | 폐기 | 요청 → 요청자와 다른 권한자 승인 → 실제 실행 → 현물 차감. 부분 실행의 잔량은 격리 유지 | 승인 초과 실행 차단. 승인만으로 차감 금지 |
| I-11 | 증빙 | 정상 작업은 스캔·수량 이력. 파손·오염·보관조건 이상·출처 불명은 식별정보와 이상 상태 사진. 폐기는 대상·실행 근거 보존 | 사진은 수량 계수·품질 판정 대체 불가. 촬영 불가 시 사유·대체 증빙을 검토하고 자동 완료 금지 |
| I-12 | 오류·오프라인 | 조회 오류와 결과 없음 구분. 응답 유실은 결과 조회 후 동일 요청 재전송. 오프라인은 스캔·계수 임시 저장만 허용 | 재연결 후 최신 주문·담당·권한·수량 재검증. 임시 저장은 확정 아님 |

### 자동 보충 계산·실행

```text
피킹선반 수량 변동 또는 설정된 점검 주기
→ 최소·목표수량/출발 재고/목적지 수용량 확인
→ 진행 중 보충·배정량 제외
→ 동일 목적지의 중복 지시 여부 검증
→ MOV 자동 생성·출발 물량 배정
→ 작업자 실제 이동·스캔·수량 확인
→ 확정된 수량만 출발 감소·목적지 증가
```

- 조건: 피킹선반 현재수량 ≤ 최소수량. 단, 계산 결과가 0 이하이면 생성하지 않는다.
- 필요량 = max(0, 목표수량 − 피킹선반 현재수량 − 진행 중 보충 예정수량).
- 지시량 = 필요량, 출발위치의 이동가능수량, 목적지 잔여 수용량 중 최솟값. 이동 단위가 있으면 초과하지 않도록 내림한다.
- 진행 중 보충·적치의 공간 배정량은 목적지 수용량 계산에서도 제외한다.
- 재계산과 지시 생성·출발 물량 배정을 하나의 처리로 관리한다. 완료·취소된 작업은 진행 중 계산에서 제외한다.
- 목적지 재배정은 관리자가 예외를 해결한 뒤 시스템이 다시 검증·계산한다. 관리자가 별도 수동 보충작업을 생성하지 않는다.
- MOV 생성은 재고 확정이 아니다. 파손·분실은 정상 이동으로 수량을 맞추지 않고 격리·조사로 분리한다.

## 3. 외부 파트 연계 적용기준

| ID | 관련 파트 | 적용 지침 |
|---|---|---|
| E-01 | 상품·주문 | 판매 옵션과 실물 SKU(상품 코드)를 환산표로 연결. 묶음 6개 × 주문 2개는 기준단위 12개 확보·피킹. 재고를 공유하는 옵션은 같은 기준재고 사용. 기존 주문의 환산값·상품정보는 버전 보존 |
| E-02 | 고객앱·배송 | 주소의 서비스 대상 PPC(피킹·포장센터) 재고만 즉시판매 노출. 주문 전 주소 변경은 센터·상품·가격·재고·배송조건 재검증. 확정 주문은 변경요청 검토 후 새 버전 적용 |
| E-03 | 상품·고객앱 | 품절·판매중지·서비스지역 밖·영업종료·처리용량 초과를 별도 원인으로 제공. 판매중지는 신규 구매 차단, 기존 주문은 중지 사유에 따라 검토. 안전·품질 문제는 대상 로트/상품의 진행 주문도 출하 보류 |
| E-04 | 주문·결제 | 장바구니는 재고 보장 아님. 최종 주문조건 재검증 후 결제 시작 직전에 재고와 필요한 슬롯을 함께 확보. 모두 확보 실패하면 성공한 확보도 해제하고 결제 시작 차단 |
| E-05 | 주문·결제 | 유효 확보와 결제 승인 확인 후 주문 확정. 결제 결과 불명은 조회 대기·중복 결제 차단. 만료 시 진행 중 결제 결과를 확인한 뒤 해제. 이미 해제된 뒤 늦은 승인이라면 같은 조건으로 재확보 가능한 경우만 복구, 불가하면 환불요청·피킹 차단 |
| E-06 | 주문·배송 | 기사 인계 전 취소·변경은 최신 주문과 작업 상태 검증 후 확정. 취소와 인계는 주문 단위로 직렬 판정. 취소 선확정이면 인계 차단, 인계 선확정이면 즉시 취소 대신 회수/반품으로 전환. 수량·상품 변경은 새 확보·금액 확정 후 작업 버전 갱신 |
| E-07 | 주문·고객지원 | 결품은 다른 위치 재확인 후 EXC(결품·대체 처리) 기록. 고객 동의로 결품분 취소·부분 출하, 조건 안내 후 대체 또는 전체 취소. 대체의 상품·수량·가격·알레르기 정보를 안내하고 추가 결제/환불 조건 확정 후 작업 재개 |
| E-08 | 고객지원·운영 | 연락 불가는 출하 보류·지원팀 이관. 무응답 자동 부분취소·임의 대체 금지. 연결된 출하 전체를 보류하고 준비된 상품은 적정 온도 보관. 원래 배송 약속 이행 불가 시 변경 동의 또는 취소 검토로 연결 |
| E-09 | 가격·혜택·결제 | 센터 결품에 의한 부분취소는 기존 배송비 유지·새 배송비 추가 금지. 원주문 상품행 할인 배분액 기준으로 취소분 환불, 남은 상품 가격 소급 변경 금지. 전체취소는 배송비 포함 환불. 전체취소 쿠폰은 유효기간 내 복원, 만료는 자동 재발급 없음. 부분취소 쿠폰은 자동 복원 없음. 고객 사유 취소·계약별 예외는 별도 정책 설정 |
| E-10 | 상품·품질·고객앱 | 상품군별 고객 수령 시 최소 잔여기한 적용·정확한 소비기한 안내 병행. 약속 수령일로 검증, 지연 시 재검증. 기준 미등록은 해당 기한관리 상품 판매 보류. 마감할인은 승인된 적합 로트별 수량에만 적용, 예약도 해당 로트에 연결 |
| E-11 | 상품·고객지원 | 안전·품질 사건은 대상 로트 출하 보류, 범위 불명은 영향 상품 검토 보류. 출고 로트 → 상품행 → 포장 → 출하 → 주문으로 추적하여 배송된 고객 지원·회수 연결. 품질담당 승인 대상만 해제, 반품전용·추적 불명은 자동 해제 금지 |
| E-12 | 주문·배송·운영 | 즉시배송과 예약배송 지원. 상품 재고와 시간대 수용량은 별도 관리·접수 시 함께 확보. 슬롯 변경은 새 슬롯 확보 성공 후 기존 해제. 작업·포장·보관·기사 여건의 등록 가능량 중 가장 작은 값으로 접수 상한 산정. 필요한 용량 미등록은 예약 접수 보류 |
| E-13 | 공급·주문·고객지원 | 확정 예정 물량은 출처·상품행·예정시각 연결, 현물 합산 금지. 수령 약속 내 도착·출하 가능한 물량만 예약에 배정. 지연·취소 시 영향 주문 추출 → 같은 조건의 다른 물량 재확보 → 불가하면 시간 변경 동의/취소. 예정 약속이 해소될 때까지 출하 자동 확정 금지 |
| E-14 | 배송·품질 | 예약 피킹은 수령시간·예상 작업/운송시간·보관 한계로 역산해 출발 가까이 요청. 준비예정시각으로 배차 병행. 기사 지연 시 온도별 보관·한계 재검증, 초과하면 출하 차단·품질 검토. 품질기준 완화 금지 |
| E-15 | 라이더·고객앱 | 온도별 복수 포장 적용. 고객에게 포장 수·구분·변경을 주문 상세에 안내. 동일 출하의 모든 유효 PKG(실물 포장 식별자)를 현재 배정 기사와 대조·실제 전달 확인한 후 HOV(기사 인계) 완료. 일부 전달은 전체완료 금지·미전달 추적. 별도 여러 차례 분할배송은 자동 제공하지 않음 |
| E-16 | 재고·배송·주문 | 고객 출하 현물 차감은 기사 인수확인된 패키지별 실제 전달 사건에 연결, 한 번만 반영. 포장완료·출고준비에는 차감하지 않음. 같은 사건에서 해당 예약/할당도 함께 소진하여 가용량이 중간에 증가하지 않게 처리. 전체 인계완료는 모든 유효 포장 전달 후. 고객 배송완료는 별도 수령 사건 |
| E-17 | 배송·고객지원·환불 | 배송실패는 안전 보관·재전달 가능 여부 검토 후 재전달 또는 회수. 회수 요청만으로 현물 증가 금지. 실제 센터 인수 시 격리 현물 증가 → 검수 → 승인된 적합품만 판매 복구. 냉장·냉동은 보관 이력 입증과 품질 승인 없으면 재판매 금지. 환불 상태와 회수/검수는 별도 관리 |
| E-18 | 고객지원·결제 | 클레임은 원주문·상품행·로트·출하·포장·전달/회수 기록 연결. 같은 피해수량에 환불·재배송 중복 승인 차단. 재배송은 새 출하와 원클레임 연결, 원출하 덮어쓰기 금지 |
| E-19 | 공급·정산 | 매입 검토 기본량은 정상 검수수량. 도착량 전체 인정은 계약 예외 승인 필요. 파손 허용률·비용 부담은 계약 등록값만 적용, 미등록은 정산 보류. 내부 이동/운송손실은 책임 확정 전 공급사 문제 거래·공제로 반영하지 않음 |
| E-20 | 개발·운영·전체 | 주문은 주문상태, 재고는 수량원장, 물류는 실제 작업/전달, 결제는 승인/환불 상태의 관리 책임을 가진다. 요청/이벤트 ID·원문서/행·버전·발생/수신시각 연결. 중복 반영·과거 버전 재개 차단. 장애 후 실물·재고·주문·결제 대사 후 재개 |
| E-21 | 운영·고객지원·개발 | 센터×직무×행위×배정작업으로 권한 검증. 재고 조정·폐기 요청/승인 분리. 사진·고객정보는 업무 필요 범위만 조회·접근 이력 보존. 정책 변경은 신규 주문부터 적용하고 기존 주문 버전 유지, 안전상 차단은 기존 주문도 적용. 코드 롤백으로 확정 기록 취소 금지 |

### 취소·출고·회수 수량 연결

```text
결제 전 확보 → 결제/주문 확정 → 피킹(선반에서 작업위치로 이동)
→ 포장(현물·확보 유지) → 기사 실제 인수(해당 현물 차감·확보 소진)
→ 고객 수령 / 전달 실패·회수
→ 실제 센터 인수(격리 현물 증가) → 검수·승인 → 판매 복구 / 반품·폐기
```

- 피킹 전 취소: 작업 차단·미집품 예약 해제.
- 피킹/포장 후 취소: 작업 중단·해당 상품 출하보류 상태 전환·예약 해제를 함께 처리. 현물은 유지하되 판매 제외. 실물 복귀·로트·품질 확인 후 판매 복구.
- 일부 포장이 이미 기사에게 전달되면 단순 전체취소로 센터 재고를 복구하지 않는다. 전달분은 회수, 미전달분은 실물 복귀 처리로 나누어 기록한다.
- 고객 표시: 주문 확인/상품 준비 중/배송 준비/배송 중/배송 완료. 취소·환불·회수 진행은 별도로 안내한다. 일부 전달은 '인계 진행·일부 포장 미전달' 예외로 표시하며 주문 전체 배송 중으로 완료 처리하지 않는다.

## 4. 설정·계약·연계 확인이 남은 항목

운영 방식은 적용했지만 아래 값은 임의로 채우지 않는다. 설정이 필요한 기능은 값이 등록되어야 실행된다.

| 항목 | 남은 값·확인 | 미등록 처리 |
|---|---|---|
| 자동 보충 | 선반별 최소·목표수량·환산량·수용량·점검 주기 | 보충 생성 보류·설정 필요 표시 |
| 실사·조정·폐기 | 순환 주기·위험상품 범위·추가 승인 임계값 | 기본 요청/승인 분리 적용, 추가 검토 대상은 승인선 확인까지 보류 |
| 재고·슬롯 확보 | 유효시간·결제 결과 조회/재시도 종료 기준 | 결제 접수 보류, 진행 거래는 확인 대기 |
| 소비기한·품질 | 상품군별 잔여기한·보관온도·최대 대기시간·해제/재판매 판정 | 해당 품목 판매/출하/해제 보류 |
| 예약배송 | 인력별 처리량·보관 가능량·기사량·접수마감·예상시간 모델 | 예약 접수/자동 준비 요청 보류 |
| 고객지원 | 연락 횟수·지원 처리기한·고객 사유 취소의 금액 정책 | 출하 보류·지원팀 판단, 무응답 자동 취소 없음 |
| 매입·정산 | 계약별 파손·비용·세무·지급 기준 | 금액 자동 확정·지급 보류 |
| 개인정보·증빙 | 보존기간·삭제조건·외부 채널/이벤트 계약·권한 담당자 | 임의 외부 전송·기한 자동 삭제 보류, 최소 권한 적용 |

수요·안전재고 산정, 공급사 점수의 가중치, 신규 협력업체 심사, 이월 종료·협의 기준 등 이번 적용 범위 밖의 미확정은 기존 상태를 유지한다.

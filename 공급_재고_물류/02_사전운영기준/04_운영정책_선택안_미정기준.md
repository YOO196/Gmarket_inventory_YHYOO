# 운영정책 — 공개 근거와 프로젝트 적용 기준

## 적용 기준
- 2026-10-13 사용자 요청으로 내부 지침·외부 연계를 문서에 적용했다. 수동 보충 요청·생성은 제외한다.
- [자동시스템 통합관리](../04_시스템_화면/01_자동시스템_통합관리.md)는 실행 참조, [내부·외부 연계 적용지침](05_재고_내부_외부연계_적용지침.md)은 적용 ID·결정·남은 설정 참조다.
- 공개 확인은 공식 자료의 해당 시점·서비스에 한정한다. 프로젝트가 선택한 방식은 업체 SOP(표준 업무 절차)·외부 팀 합의로 단정하지 않는다.
- 원본 선택표는 도메인 문서의 조사 이력으로 보존한다. 현재 적용값은 아래 및 적용지침을 따른다.

## 운영정책 적용표

| 항목 | 프로젝트 적용 | 남은 설정·확인 |
|---|---|---|
| 로트 | 입고일·공급사·상품·소비기한, 확인된 제조/공급사 로트 추가 분리. 자동 병합 금지 | 상품별 추적 필수정보 등록 |
| 혼재·적치 | 실물 식별·구획·수량 분리 가능 조건에서만 허용 | 위치 보관조건·수용량 |
| 선반 보충 | 최소 이하 자동 계산·MOV 자동 생성. 수동 보충 제외 | 최소·목표·주기·단위 |
| 실사 | 순환 실사·계수 위치 잠금·다른 작업자 재계수 | 주기·전수 실사 계획 |
| 조정·폐기 | 요청/승인 분리, 기본 권한자 승인, 실제 결과 한 번 반영 | 위험 범위·추가 승인 임계값 |
| 소비기한 | 고객 수령 최소 잔여기한·정확한 소비기한 안내 병행 | 상품군 기한·온도·대기한계 |
| 격리·회수 | 실제 인수 후 격리 현물, 품질 검수·승인 후 적합품 판매 복구 | 해제·재판매 판정값 |
| 사진 | 정상 작업 스캔/계수 이력, 이상·폐기 대상/실행 증빙 | 보존기간·대체 증빙 승인 |
| 파손·매입 | 정상 검수량 기본 검토, 전체 도착 인정은 계약 예외 승인 | 계약 파손률·책임·비용 |
| 확보·결제 | 결제 직전 재고/슬롯 확보, 유효 확보+승인 후 주문 확정, 불명 조회·늦은 승인 복구/환불 | 유효시간·조회/복구 종료 기준 |
| 결품·연락 불가 | 고객 동의 대체/부분출하/전체취소, 무응답은 출하 보류·지원 이관 | 연락·지원 처리기한 |
| 부분 환불 | 센터 결품은 기존 배송비·원할인 배분 유지. 전체취소는 배송비 포함 환불·유효 쿠폰 복원 | 고객 사유·계약 예외 |
| 출고·차감·인계 | 포장/준비와 인계 분리. 기사 인수확인된 포장별 실제 전달 시 현물 차감·확보 소진 | 외부 인수확인 연계 |
| 예약·예정 | 즉시/예약, 재고와 슬롯 동시 확보. 예정 지연은 대체 확보/일정 동의/취소 | 단계별 용량·마감·시간 모델 |
| 준비·배차 | 품질 구간 안에서 출발 가까이 준비, 준비예정시각으로 배차 병행 | 보관/작업/운송 시간 설정 |
| 포장 | 온도별 복수 포장·포장 수/구분 안내, 유효 전량 전달 후 전체완료 | 상품별 포장 구성 |
| 연계·권한 | 상태 관리 책임·ID/버전·중복 방지·대사. 센터/직무/행위 권한·접근 이력 | 채널 계약·보존기간 |

## 공개 근거·미확인 범위
- B마트 수량·품질·소비기한 검수, 목포 PPC의 보냉/대기/동선 사례, OMS의 예약·예정재고·부하 분산·마감할인 확인 범위는 기존 조사를 따른다.
- 쿠팡 분산 적치·ICQA(재고 수량·품질 점검)·마감세일은 공개 범위 내에서만 인용한다.
- 업체 로트 생성·실사 잠금·차감 사건·무응답·매입 파손 허용률·승인 임계값은 공개 미확인이다. 이번 문서 적용과 구분한다.
- [실사례 조사·27개 비교](../05_실사례_근거/01_쿠팡_B마트_실사례조사.md)는 수정하지 않고 근거 자료로 보존했다.

## 유지하는 미확정
- 공급사 심사·평가 가중치, 수요·안전재고 모델, 기존 PO/ASN 이월 종료·협의·잔량 해소, 세무·지급 상세는 기존 미확정 유지.
- 수치·계약 미등록은 해당 자동 실행 보류. 구체 미등록 처리·담당 영역은 [적용지침 4절](05_재고_내부_외부연계_적용지침.md) 참조.

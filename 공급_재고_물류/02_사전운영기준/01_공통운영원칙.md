# 사전 운영기준·공통 원칙

## 1. 먼저 구분할 문서 상태
| 표기 | 뜻 | 적용 |
|---|---|---|
| 프로젝트 규칙 | 채번·식별·연결·중복방지 등 현재 문서가 정한 공통 규칙 | 도메인·시스템 문서에서 동일하게 적용 |
| 실사례 확인 | 공개 자료의 특정 시점·서비스·센터에서 확인 | 실제 업체 모든 센터의 현행 표준으로 확대하지 않음 |
| 제안 | 검토 중인 추천식·자동화·업무 방식 | 채택 전 자동 실행·확정 기본값으로 사용하지 않음 |
| 선택안 | 원본의 복수 방안 | 선택·적용범위를 결정한 뒤 적용 |
| 미정 | 계약·시간·수량·비율·승인·판정 기준 미확정 | 임의 기본값 추가 금지 |

## 2. 업무 시작 전 확인
- 사용자·센터·직무·행위·배정작업·승인 권한 확인.
- 상품·바코드·구매단위·환산량·보관조건·로트·위치 속성 확인.
- 공급사 계약·납품·지급조건과 적용 버전 확인.
- 미확정 설정은 미등록 상태로 표시. 담당자 검토 없이 자동 승인하지 않음.
- 날짜·번호·센터·상품 정보는 채번 규칙과 기준정보로 각각 관리.

## 3. 공통 수량·상태 원칙
| 구분 | 적용 기준 |
|---|---|
| 입고 | 실제 도착·인수·검수 상태를 구분. 인수 전 반송은 센터 현물에 더하지 않음 |
| 수량 분해 | 정상·파손 격리·기타 품질 보류는 중복 없이 인수수량을 구성 |
| 품질 | 격리품은 센터 현물에 포함·판매 제외. 해제 허용과 반품 전용 구분 |
| 매입 | 입고량·납품 이행 인정량·매입 인정량은 서로 다름. 계약 검토 |
| 내부 이동 | 출발위치 감소·목적지 증가·센터 총량 유지 |
| 센터 이송 | 출발 현물 → 이동 중 → 도착 현물. 부분 도착만 반영 |
| 전체 현물 | DC·PPC·센터 간 이동 중 중복 없이 합산. 예정 물량 제외 |
| 출하 | 준비·출고확정·실제 전달·원장 반영 별도. 원장 차감 사건은 미정 |
| 처분 | 승인만으로 현물 감소 금지. 반품 반출·폐기 실행 결과 확인 |

## 4. 공통 문서·확정 원칙
- 번호 발급은 문서 생성이며 승인·확정·실행·재고/매입 반영이 아님.
- 원문서·상품행·실제 결과·반영 기록 연결. 동일 요청은 한 번 반영.
- 확정 후 원기록 보존. 정정·역처리·조정 이력으로 수정.
- 오프라인 임시 기록은 최종 확정과 구분. 재연결 후 상태·권한 검증.
- 이월은 기존 PO(구매발주) 유지·기존 ASN(공급사 납품예정) 수정 또는 새 차수. 종료·협의·잔량 해소 기준은 미정.

## 5. 예외·승인
- 수량·품질·권한·위치 불일치 시 처리 차단 또는 검토 요청.
- 부족·초과·파손·미도착은 실제 수량·근거 보존. 자동 폐기·임의 수량 맞춤 금지.
- 책임 미확정·센터 책임 유실은 공급사 문제 평가에서 제외. 책임 판정 후 적용 여부 확인.
- 고객 동의 없는 대체 금지. 무응답 처리는 선택 정책 확정 전 임의 실행 금지.
- 기준 숫자·승인선·주기·사진 의무·원장 차감 사건은 [운영정책·미정기준](04_운영정책_선택안_미정기준.md) 확인.

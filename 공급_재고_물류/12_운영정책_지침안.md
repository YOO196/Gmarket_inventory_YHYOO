# 운영정책 — 실사례 우선 정리

## 적용 기준
- 공개 확인: 공식 자료의 해당 시점·센터·서비스에서 확인된 내용.
- 프로젝트 규칙: 사용자 채번 지침·원문 업무 요구·구현안. 업체 내부 SOP(표준 업무 절차)와 구분.
- 정책 미정: 공개되지 않은 금액·비율·시간·승인선. 임의 숫자를 기본값으로 사용하지 않음.
- [27개 항목 조사](14_미정정책_쿠팡_B마트_실사례조사.md)에서 근거·미확인 범위 확인.

## 1. 로트·채번
| 구분 | 기준 |
|---|---|
| 공개 확인 | B마트 수량·품질·소비기한 검수. Lot 생성·병합 SOP(표준 업무 절차)는 미확인 |
| 사용자 정의 | 내부 Lot ID·공급사 Lot값 분리. 입고 상품행까지 추적 |
| 원문 구분안 | 입고일·공급사·상품·소비기한. 실제 업체 기준으로 단정하지 않음 |
| 미정 | 제조 로트 중심 구분·입고 간 병합·정보 누락 처리 |

- 위치 이동은 제조 Lot정보 변경이 아님.
- 내부 ID 발급과 품질 적합 판정 구분.
- 공급사 입고는 RCV(입고·검수), 센터 이송 도착은 TIN(이송 도착) 참조.
- [문서 채번](00_ERP·WMS%20업무%20문서%20채번%20지침.md)과 [위치주소](00_DC_PPC_구역_위치번호_운영웹.md) 분리.

## 2. 소비기한·품질·마감할인
| 확인된 운영 | 프로젝트 적용·미정 |
|---|---|
| B마트 전담 신선 검품·품질 미달 판매 제외 | 품질 부적합과 기한 임박 구분 |
| B마트 OMS(주문·출고 관리) 소비기한·수요 기반 마감할인 | 대상·수량·할인율 정책은 별도 결정 |
| 쿠팡 QC(품질 검사) 검수를 거친 임박상품 마감세일 | 할인·고객 동의가 품질검수 대체하지 않음 |

```text
검수·기한 확인 → 판매 적합 / 격리 구분 → 재검수·처분 판단 → 승인된 상태 반영
```
- 최소 잔여기간·기한 종료시각·격리해제 권한은 상품별 확인 필요.
- 같은 위치의 복수 로트는 식별·수량 분리. 물리 혼재는 위치 정책으로 결정.
- 반품 양품화 사례를 냉장·냉동 식품의 재판매 허용 근거로 전용하지 않음.

근거: [B마트 목포 PPC](https://bcut.baemin.com/7369/), [B마트 OMS](https://techblog.woowahan.com/22263/), [쿠팡 마감세일](https://news.coupang.com/archives/21652/).

## 3. 파손·매입 인정
| 단계 | 프로젝트 처리 |
|---|---|
| 검수 | 도착·정상·파손·미납품 구분 |
| 품질 | 판매 적합성·반품·폐기 판단 |
| 매입 | 계약·협의에 따라 PUR(매입확정) 인정수량·금액 검토 |
| 확정 후 조정 | 원 PUR(매입확정) 보존·PJA(매입 조정) 연결 |

- 양사 직매입 파손 허용률·전체 매입 예외는 공개 미확인.
- 종전 파손 허용 0% 기본값 제거. 계약 미등록은 '조건 미확인'.
- 품질 부적합과 비용 부담은 별개.
- 예외 건 자동 지급 확정 보류는 원문 프로젝트 통제안. 실제 지급 SOP(표준 업무 절차)로 단정하지 않음.
- DC(중앙 물류센터)→PPC(피킹·포장센터) 내부 이송은 동일 상품의 신규 매입으로 중복 반영하지 않음.
- 위탁형 로켓그로스 약관을 직매입 정산 기준으로 사용하지 않음.

## 4. 사진·폐기 승인
| 대상 | 기록 | 미정 |
|---|---|---|
| 입고 이상 | 문서·상품행·수량·사유·증빙 | 정상 입고 사진 의무·컷 수 |
| 품질 | QLT(품질 격리)·Lot·검수 근거 | 촬영 조건·보관기간 |
| 반품·폐기 | RTV(공급사 반품)/DSP(폐기)·승인·실제 실행 | 승인자 수·금액·수량 임계값 |
| 인계 | HOV(기사 인계)·유효 PKG(실물 포장 식별자)·기사·전달 결과 | 스캔·사진 의무 범위 |

- 공개 근거 없는 10만원·100개 추가 승인값 제거.
- 승인·실행 분리, 실제 처리 전 현물 유지는 프로젝트 규칙.
- 결재선·요청자와 승인자 분리 여부는 운영 권한표로 확정.
- 사진만으로 계수·품질·인계를 확정하지 않음.

## 5. 실사·조정
공개 확인: 쿠팡 ICQA(재고 수량·품질 점검) 전산기록 모니터링·실물 수량 확인. 잠금 범위·주기·조정 승인값은 미확인.

```text
CNT(재고 실사) 대상·기준시각 → 계수 → 차이 재확인·변동 대조 → 잔여 차이 ADJ(재고 조정) → 승인·반영
```

| 선택안 | 적용 조건 — 프로젝트 검토 |
|---|---|
| 대상 위치 잠금 | 진행중 이동 정리·입출고 제한 가능 |
| 운영 중 실사 | 기준시각 이후 변동을 빠짐없이 대조 가능 |
| 품목별 순환 | 점검 대상·주기 결정 |
| 전수 실사 | 정기·감사·반복 오차 등 목적별 계획 |

- 실사 방식은 아직 선택안. 업체 기본 SOP(표준 업무 절차)로 표시하지 않음.
- 차이를 즉시 분실·폐기로 확정하지 않음. 같은 차이의 ADJ(재고 조정)·DSP(폐기) 이중 차감 방지.
- 계수자·재계수자·승인자·기준시각·변동 근거 기록.

근거: [쿠팡 ICQA](https://news.coupang.com/archives/19934/).

## 6. 결품·고객 무응답
양사 피킹 결품 대체·부분출하·전화 횟수·무응답 시간의 공개 근거 미확인.

| 단계 | 프로젝트 흐름 | 확인 |
|---|---|---|
| 발견 | EXC(결품·대체 처리)·부족수량 기록 | 원주문·대상 행 |
| 고객 확인 | 취소·대체·전체취소 선택 요청 | 가격·수량·동의 |
| 연락 불가 | 보류·지원팀 이관 검토 | 대기·보관·사전 동의 정책 |
| 변경 확정 | ORD(고객 주문)·OCN(고객 주문 취소)·RFD(환불)·예약 갱신 | 처리자·근거·환불 상태 |

- 종전 3분·5분·전화 1회 고정값 제거.
- 미확정 무응답 자동 취소·임의 대체 실행 금지.
- 대체상품·알레르기 안내·환불 재산정은 고객 시스템 정책으로 확정.
- 예약 스케줄의 재고부족 SKIP과 실제 피킹 결품 고객 연락은 별개.

## 7. 출고·차감·기사 인계
| 사건 | 기록 | 관계 |
|---|---|---|
| 예약·할당 | 확보 수량 | 가용과 현물 분리 |
| 피킹 | 선반·토트·작업 위치 | 내부 이동 |
| 포장완료 | SHP(출하)·유효 PKG(실물 포장 식별자)·준비시각 | 인계와 별도 |
| 기사 인계 | HOV(기사 인계)·전달·인수 결과 | 일부·전체 전달 구분 |
| 원장 차감 | 근거 사건·반영 ID·시각 | 정책 확정 후 한 번만 반영 |

- 양사 실제 차감 이벤트 미확인. 기사 인계 시 차감을 확정 기본값에서 제외.
- 포장/출고확정 또는 인계 등 선택 시 취소·회수·정정까지 함께 정의.
- 부분 인계 시 실제 전달분·미전달분 추적. 전체 PKG(실물 포장 식별자) 전달 전 전체 인계완료 금지.
- 원장 차감시점과 무관하게 실제 공간·전달 상태 기록.
- 전부 전달 전까지 센터 현물을 무조건 유지하면 부분 인계와 어긋날 수 있음. 자동 적용 금지.
- 출고 준비와 배차는 병행 가능. 예상 준비시각 활용.
- TRF(센터 간 이송)·TOUT(이송 출발)·TIN(이송 도착) 이송 및 이동중 수량 규칙은 사용자 문서·재고 설계 유지.

## 8. 예약·작업 용량·대기
공개 확인: B마트 예약배달·입고예정 판매·출고 부하 분산·동적 준비시각.

```text
예약 → 현재·예정·할당 재고 확인 → 품질 보존 구간·작업 여유 확인
→ 출고요청 / 수령시간에 맞춘 배달요청 → 준비완료·인계·배송
```

| 항목 | 실사례 우선 기준 |
|---|---|
| 작업 여유 | 목표생산성·작업가능 인원·현재 출고량 |
| 요청 분산 | 출고요청·배달요청 분리·품질 보존 구간 |
| 예정재고 부족 | 우선 SKIP·배송 가능한 마지막 시점에 출고 요청하는 사례 |
| 라이더 대기 | 현장 여건 기반 출고예정시각 |

- 고객 슬롯 판매 상한과 출고 작업 가능량은 다른 지표.
- 종전 최소능력×0.8·시간당 고정 건수 공식 제거.
- 슬롯 상한·접수마감·최대 대기시간·마지막 시점 결품 대응은 미정.
- 목포 PPC(피킹·포장센터)의 포장 후 냉장 대기는 해당 포장·보냉 사례. 모든 냉동품 보관조건으로 일반화하지 않음.

근거: [B마트 OMS](https://techblog.woowahan.com/22263/), [목포 PPC](https://bcut.baemin.com/7369/).

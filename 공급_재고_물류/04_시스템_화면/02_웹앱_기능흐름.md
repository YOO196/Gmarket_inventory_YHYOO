# 최종 웹·앱 기능 흐름

## 1. 적용 범위
- DC(중앙 물류센터)·PPC(피킹·포장센터) 역할·예약·작업 분산은 공개 사례 우선 반영.
- 메뉴·공통 웹·승인 화면·번호는 프로젝트 구성. 실제 업체 UI 아님.
- 업체 확인범위는 [조사](../05_실사례_근거/01_쿠팡_B마트_실사례조사.md), 미결정 기준은 [정책](../02_사전운영기준/04_운영정책_선택안_미정기준.md) 참조.

## 2. 서비스·권한
| 서비스 | 첫 화면·메뉴 |
|---|---|
| 본사 운영 웹 | 전체 재고·센터·이관·지연·예외 관제 |
| DC(중앙 물류센터) 운영 웹 | 공급사 입고·보관·PPC(피킹·포장센터) 보충요청·할당·상차 |
| PPC(피킹·포장센터) 운영 웹 | 이관 도착·재고·주문·예약·피킹·포장·인계 |
| 품질·정산 역할 | 품질 검토·처분·매입·조정 등 허용 업무 |
| 공급사 포털 | 입점·상품등록 신청·발주 확인·ASN(공급사 납품예정)·변경 협의·정산 |
| 현장 PDA(현장 작업 단말) | 내 작업·스캔·계수·문제보고·전송상태 |
| 기사 기능 | 이송 또는 배달 배정·인계·지연 |
| 고객 앱 연계 | 상품·배송약속·예약·주문 변경 안내 |

```text
로그인 → 접근센터 확인 → 작업센터 선택 → 당일 직무·행위권한 확인 → 내 업무
```
- DC(중앙 물류센터)·PPC(피킹·포장센터)는 한 운영 웹 안에 다른 대시보드 제공 권고.
- PDA(현장 작업 단말)·관리자 화면 통합 여부는 기존 검토 유지. 승인 권한은 별도.
- 메뉴 표시와 서버 권한 검증 모두 필요. 상대센터 전체 조회 권한 자동 부여 금지.

## 3. 단계별 화면 연결
| 단계 | 화면·담당 | 처리·문서 | 다음 단계 | 문제 지침 |
|---|---|---|---|---|
| 1 | 상품·공급사 | 공급사·상품등록 신청·단위 검토 | 발주 | 기준정보 확인 후 진행 |
| 2 | 관리자 발주 | PO(구매발주)·수량·센터 지정 | 공급사 확인 | 변경 PCH(발주 변경 요청)·잔량 PCN(발주 잔량 취소) |
| 3 | 공급사 포털 | 수락·ASN(공급사 납품예정) 등록 | DC(중앙 물류센터) 입고예정 | 납기·초과·잔량 협의 |
| 4 | DC(중앙 물류센터) PDA(현장 작업 단말) | RCV(입고·검수)·실수량·품질·기한 검수 | 보관·품질·매입 | 정상/보류 분리·근거 기록 |
| 5 | DC(중앙 물류센터) 재고·이관 | TRF(센터 간 이송)·로케이션 할당 | 집품·상차 | 미할당·부분할당·할당 구분 |
| 6 | DC(중앙 물류센터) 출발·운송 | TOUT(이송 출발)·실제 출발 | PPC(피킹·포장센터) 도착 | 출발·이동중 추적 |
| 7 | PPC(피킹·포장센터) PDA(현장 작업 단말) | 실제 도착 TIN(이송 도착)·품질 확인 | 적치·판매 준비 | 미도착 잔량 조사 |
| 8 | 고객·OMS(주문·출고 관리) 연계 | ORD(고객 주문)·SHP(출하)·현재/예정/할당 재고 | 출고 요청 | 예약 약속·현물 구분 |
| 9 | 주문·작업 관제 | 현장 여유·품질 구간·TSK(작업 식별자) | PDA(현장 작업 단말) 피킹 | 예정재고 부족 스케줄 보류 |
| 10 | PPC(피킹·포장센터) 피킹 | 토트·위치·상품·수량 | 포장 | 실제 결품 EXC(결품·대체 처리)·고객 처리 |
| 11 | PPC(피킹·포장센터) 포장 | 유효 PKG(실물 포장 식별자)·라벨·준비완료 | 품질 유지 대기 | 재포장·라벨 재출력 구분 |
| 12 | 배달 연계 | 준비예정시각·배달 요청 | 기사 도착 | 피킹·포장과 병행 가능 |
| 13 | 현장·기사 | SHP(출하)·PKG(실물 포장 식별자)·HOV(기사 인계) 전달 확인 | 배송 | 일부만 전달 시 전체 완료 금지 |

매입 PUR(매입확정)·정산 PJA(매입 조정)는 공급사 입고·계약에 연결. 내부 TIN(이송 도착)은 신규 매입이 아님.

## 4. DC(중앙 물류센터) 이관 상세
```text
PPC(피킹·포장센터) 보충 수요 → DC(중앙 물류센터) TRF(센터 간 이송) 생성 → SKU(상품 코드)별 로케이션 할당
→ DC(중앙 물류센터) 집품·목적지 검품 → 출하대기 → 상차·TOUT(이송 출발) → 운송 → PPC(피킹·포장센터) TIN(이송 도착)
```
- 공개 B마트 사례: 자동·수동 위치 할당, 취소는 미할당 상태만 가능.
- 할당된 요청의 취소는 확보 재고·실작업 상태 확인 필요. 해제·회수는 별도 정책.
- 부분 도착마다 새 TIN(이송 도착). 기존 도착수량 덮어쓰기 금지.
- 12병 출발·10병 도착이면 2병 잔량 유지·조사. 즉시 폐기하지 않음.

## 5. 바로배달·예약배달 상세
```text
바로배달: 주문·출고가능 판단 → 출고요청·준비예정 → 작업·배달 요청 → 인계
예약배달: 수령시간·예정재고 약속 → 입고 확인·현장 여유·품질 구간
          → 작업 분산 / 수령시간 맞춘 배달 요청 → 준비·인계
```
- 현물 부족만으로 모든 예약 주문을 즉시 거절하지 않음. 예정재고 활용 사례 반영.
- 예정 물량을 현재 현물에 더하지 않음. 출고 직전 실제 물량 확인.
- B마트 재고부족 예약 작업 SKIP 사례 반영. 최종 부족 시 취소·연락 규칙은 미확인.
- 고객 슬롯 판매 상한과 현장 처리 가능량을 구분.
- 고정 '주문 후 10분' 대신 현장 여건을 반영한 준비시각 산정 사례 참고.

## 6. 피킹 결품·교대
| 상황 | 프로젝트 흐름 | 미결정 |
|---|---|---|
| 피킹 부족 | EXC(결품·대체 처리)·부족수량 → 고객 확인 → 변경 ORD(고객 주문)·OCN(고객 주문 취소)·RFD(환불) | 대체·부분출하·사전 동의 |
| 연락 불가 | 출하 보류·지원 검토·품질 유지 | 대기시간·자동취소 |
| 교대·지연 | 완료분·잔여분·실물 토트 → 담당 변경·같은 TSK(작업 식별자) | 강제/수락 방식 |
| 늦은 스캔 | 권한·담당·작업 상태 재검증 | 충돌 처리 권한 |

## 7. 포장·배차·인계
```text
피킹 → 조건별 포장·PKG(실물 포장 식별자) → 라벨·전체 구성 확인 → 준비완료·품질 유지 대기
                                    배차/배달요청은 준비예정시각 기준 병행
→ 기사·유효 PKG(실물 포장 식별자) 확인 → 실제 전달 추적 → 전체 전달 시 HOV(기사 인계) 완료
```
- 실물 교체: 새 PKG(실물 포장 식별자)·기존 무효·교체 관계. 라벨 재출력: 같은 PKG(실물 포장 식별자).
- 포장완료·준비완료·인계완료·원장 반영 각각 기록.
- 차감 시점은 미확정. 선택한 사건으로 한 번만 반영·취소/회수 보정.
- 일부 전달된 실물은 센터에 있는 것으로 무조건 유지하지 않음. 위치·수령 상태 추적.
- 상품별 포장·온도·대기한계 등록. 현장 사례 온도를 모든 상품에 적용하지 않음.

## 8. 품질·실사·정산
| 업무 | 흐름 | 완료 판단 |
|---|---|---|
| 품질 | QLT(품질 격리) → 재검수 → 해제/RTV(공급사 반품)/DSP(폐기) | 상태 판정·실제 실행 |
| 마감할인 | 적합 재고·소비기한·수요 → 할인 대상/수량/율 | 우리 상품 정책 미정 |
| 실사 | CNT(재고 실사) → 계수·재계수·이동 대조 → ADJ(재고 조정) | 승인 근거·반영 결과 |
| 매입 | PO(구매발주)·RCV(입고·검수)·계약 → PUR(매입확정) → 확정 후 PJA(매입 조정) | 인정수량·금액·조정 |

- 계약·기한·결재 수치를 임의 기본값으로 넣지 않음.
- 배송 지연은 품질 점검·보관·시간·안내 조정. 품질 기준 완화로 해결하지 않음.

## 9. 공통 오류·전송
| 상황 | 처리 |
|---|---|
| 조회 결과 없음 | 예정/작업 없음 안내 |
| 조회 실패 | 실패 표시·재조회 |
| 오상품·오위치·권한 불일치 | 처리 차단·대상 안내 |
| 오프라인 | UUID(중복 방지용 고유 요청번호) 임시저장. 최종 확정과 구분 |
| 응답 유실 | 기존 결과 조회·같은 요청 ID 재전송 |
| 확정 후 오류 | 원기록 보존·정정/역처리/조정 |

## 10. 관련 정의·구현 순서
- [채번](../02_사전운영기준/03_업무문서_채번지침.md), [센터·구역](../02_사전운영기준/02_센터_구역_위치번호.md), [정책](../02_사전운영기준/04_운영정책_선택안_미정기준.md), [조사](../05_실사례_근거/01_쿠팡_B마트_실사례조사.md).
- 구현안: 기준정보·권한 → PO(구매발주)/ASN(공급사 납품예정)/RCV(입고·검수) → 재고·TRF(센터 간 이송)/TOUT(이송 출발)/TIN(이송 도착) → ORD(고객 주문)/SHP(출하)·작업 → 포장·인계 → 정산·예외 → 예약 분산·할인 고도화.
- 화면에서 실제 업체 사례와 프로젝트 기능을 구분하되, 상품 사용자에게 내부 구현 설명을 노출할 필요는 없음.

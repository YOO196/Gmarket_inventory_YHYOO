## 적용 우선순위

- 사용자 요청으로 적용한 [내부·외부 연계 적용지침](02_사전운영기준/05_재고_내부_외부연계_적용지침.md)과 [자동시스템](04_시스템_화면/01_자동시스템_통합관리.md)을 현재 프로젝트 운영기준으로 읽는다.
- 실제 업체 설명은 마지막 실사례 문서의 시점·범위만 인용한다. 이번 프로젝트 결정은 업체 SOP·외부 팀 합의 완료가 아니다.
- 원본 복수 방안은 조사 이력으로 보존한다. 수동 보충은 적용 대상에서 제외한다.
- 미등록 수치·계약·연계는 설정/검토 대기. 이번 범위 밖의 미확정·기존 PO/ASN 이월 정의는 유지한다.

## 이번 검토에서 정리한 충돌

- 수동 선반 보충 제거·시스템 계산/MOV 자동 생성으로 통일.
- 실사 방식은 순환 실사/계수 위치 잠금, 재계수 담당 분리·조정/폐기 요청 승인 분리 적용.
- 결제 전 확보·취소/인계 직렬 판정·기사 실제 인수확인 시 포장별 현물 차감·확보 소진 적용.
- 연락 불가는 보류/지원 이관, 예정 지연은 대체 확보·일정 변경 동의/취소로 연결.
- 회수품은 실제 인수 후 격리·검수/승인 후 판매 복구. 환불 상태와 구분.
- 공급사 평가·수요/안전재고·이월 마감 등 범위 밖 미확정 유지. 실사례 문서 원본 보존.

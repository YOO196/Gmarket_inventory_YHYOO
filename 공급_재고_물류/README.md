## 적용 우선순위
- 프로젝트 공통 규칙·사용자 채번을 일관되게 적용한다. 실제 업체 코드로 단정하지 않는다.
- 실제 운영 설명은 실사례의 시점·서비스 범위 안에서 사용한다.
- 원본의 제안·복수 선택지는 도메인에 보존. 확정 운영값과 구분한다.
- 자동시스템의 미확정 항목은 미정으로 유지. 새로운 이월 대장 방식은 반영하지 않는다.

## 이번 검토에서 정리한 충돌
- 도착량·인수량·검수 상태별 합계 분리. 기타 품질 보류를 파손으로 처리하지 않음.
- 정상 검수 관리자 승인 생략·다른 작업자 재계수는 제안이며 승인 범위는 미정.
- 격리 적합 판정만으로 반품 전용 대상을 자동 해제하지 않음.
- 실사 잠금·전수/순환·고객 무응답 방안을 확정 기본값처럼 적은 표현 수정.
- 원장 차감 사건은 미정. 실제 전달 상태와 별도 기록.
- 공급사 거래 실적 점수는 제안식 상한 이후 유지. 책임 미확정·센터 유실은 공급사 평가 제외.
- Mermaid 도표의 괄호 포함 문구를 따옴표로 감싸 파싱 오류 수정.

기존 자료·원본 이미지는 보존. 폴더의 이전 MD는 역할별 하위 폴더로 이동했고 참조 링크를 갱신했다. 구조 변경 전 사본은 작업용 백업에 보관.

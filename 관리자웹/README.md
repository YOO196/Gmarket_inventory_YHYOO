# 공급·재고·물류 관리자 웹 시안

프로젝트 문서를 이해하기 위한 가상 데이터 시안. 실제 B마트·쿠팡 운영 화면이 아님.

- 작업·출하 관제, 전체 현황, 협력업체·상품, 구매·발주, 입고·검수, 재고·센터 이관, 품질·실사, 매입·정산, 포장·기사 인계, 예약 출고, 장비·전송 상태, 업무 정의·도움말.
- 첫 화면: 작업 목록·상태 요약·대기시간 TOP 5·교대 이력. 작업번호를 누르면 스캔 이력과 담당자 인계 확인.
- 포장 교체: PKG 002 무효·004 생성. 전체 유효 포장 전달 전 인계 완료 차단.
- 품질·실사: 격리 피킹 제외·조정 검토 요청. 정책 미결정 항목은 자동 승인하지 않음.
- 도움말에 최신 아웃풋 문서 17개를 내장. 인터넷 없이 업무 정의 확인.
- 흐름 안내에서 시작하거나 왼쪽 메뉴로 이동.
- 한빛음료: 발주 100개 → 공급 가능 80개 회신 → 양사 합의·20개 취소 → ASN·출하.
- 프레시팜: 출하 100개 → 실입고 100개 → 정상 95·파손 5 → 계약 확인 후 매입 인정 검토.
- 이관: DC 출발 12개 → PPC 도착 10개 → 미도착 2개 조사.
- 승인·발주 초안·검수·지급 기록은 브라우저 로컬 저장. 실제 계정 인증·발주 전달·재고·송금 연동 없음.
- 화면의 센터 선택은 작업 관제·전체 현황·재고 조회에 적용. 다른 화면은 고정 예시 거래.
- 시연 데이터 초기화로 저장된 작업을 되돌릴 수 있음.

`관리자웹_미리보기.html`을 더블클릭해 Edge 또는 Chrome으로 열면 됩니다. 화면과 동작을 한 파일에 담았으며 인터넷·설치·서버 실행이 필요 없습니다. 별도 소스는 `dist/`에 보존했습니다.

참고: [쿠팡 Supplier Hub](https://supplier.coupang.com/welcome/join/guide.html), [우아한형제들 협력사 가이드](https://epro.woowahan.com/resources/login/contents/guide.pdf). 세부 메뉴·상태·권한은 프로젝트 설계.
